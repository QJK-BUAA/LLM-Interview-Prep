## 确认问题与修法

### F05-1（数学条件）：可微不保证中心差分有二阶截断误差

- 位置：05 `math-gradient-check`。只先假定“可微标量损失”，随后给出误差 `O(epsilon²)`。
- 反例：`f(x)=x|x|` 在 0 处可微，导数 0，中心差分等于 `epsilon`。独立 Python 在 0.01、0.001 处分别算出 0.01、0.001；误差是一阶，不是二阶。
- 修法：写明二阶截断误差依赖检查点附近三阶导数有界等足够光滑条件；不可导边界、随机层的已有说明保留。

### F05-2（代码解释）：均值已经进入上游，不能再平均

- 位置：05 `code` 末段“真实训练还会在 batch 维取平均”。
- 代码已用 `loss=0.5*((y_hat-y)**2).mean()` 和 `g_y_hat=(y_hat-y)/y_hat.size`，平均已完成。正文也强调不能每层重复平均。
- 修法：改为“本例已按全部输出元素取平均；真实训练再处理……”，提醒多输出任务要声明按样本还是元素平均。无需更改正确梯度代码。

### F06-1（跨章条件）：速记不应把 clipping 写成硬约束

- 位置：06 `diagram` 的“梯度裁剪限制异常更新”；`pitfall` 第一项“防止一次异常更新”“PPO clip……限制策略离采样策略过远”。
- 本章已正确证明裁剪界是梯度界，只直接推出普通 SGD 更新界；Adam 的历史和预条件不受同一个界限制。
- PPO clipping 限制的是样本 surrogate 的局部激励，不投影参数或策略到概率距离球；共享参数、多轮更新仍可能越过 clip 区间。待 19 完整审查时统一对应表述。
- 修法：明确“限制梯度范数”“抑制超出区间的部分更新激励，但不保证概率比或 KL 硬界”，保留 19 的后续入口。
- 附带措辞：critical batch 之后的收益通常趋于饱和，不宜写成某个阈值后步数绝对“不再减少”。

### F07-1（实现条件）：平方中间显存限定为朴素注意力

- 位置：07 `diagram`，“标准注意力需要构造 S×S 关系矩阵，长序列计算和显存随长度平方增长”。
- 数学上存在全对全分数，朴素实现物化该矩阵；11 已正确推导精确 FlashAttention 可以不在 HBM 中保存它。因此“标准/精确注意力必有平方中间显存”不成立。
- 修法：用“朴素实现显式保存……；精确分块实现仍有二次算术量，但可避免平方中间存储，见 11”。无需展开 11 的推导。

### F09-1（代码接口）：0/1 padding mask 不能直接加到 scores

- 位置：09 `code`，`scores = scores + causal_mask(scores) + attention_mask`。
- 08 已把 `attention_mask` 定义成 `[B,S]` 的 0/1，有效=1、pad=0。09 没有在代码里转换，也没有声明传入的是 `[B,1,1,S]`、0/负无穷的加性 mask。
- 独立反例：两键分数全 0，直接加 `[1,0]` 后 softmax 为 `[0.731059,0.268941]`，pad 仍有约 27% 权重；正确结果是 `[1,0]`。一般 B>1 时还会发生广播轴不匹配。
- 修法：明确接收二值 key mask、在使用前转换和扩轴，或改参数名并展示调用端构造；代码必须与 08 接得上。声明全屏蔽 query 的处理规则，不能靠 loss mask 清理前向 NaN。
- 验证：应有真实行为回归，检查 pad 权重、causal 权重和 batch 广播，不写只比对字符串的测试。

### F09-2（明确目标缺口）：整网前向与位置注入还没有代码落点

- 位置：09 objective“写出 decoder-only 语言模型的完整前向伪代码”，与 `code` 只提供 `decoder_block`、最后用一句话描述完整网络。
- 当前代码没有位置表示，整网的一句描述也只提 token embedding、block、final norm、head 与 shift；08 正文的位置说明没有在这里落成调用。
- 修法：在保留 block 的前提下补短小的整网伪代码，明确选择一种位置方案（例如此章用绝对位置查表，10 再换 RoPE），接好二值 mask 转换、层循环、final norm、head 和仅一次的 label shift/有效 loss 计数。防止读者照抄出无显式位置输入或预测自身的模型。

### F10-1（术语）：延长位置不会自动改变 RoPE 频率

- 位置：10 `derivation`，“长于训练窗口时，旋转频率落入未见区域”。
- `theta_i` 在原模型里固定；变化的是 `m theta_i` 的相位和跨位置组合。扩窗方法可以另行修改频率，但不能把延长 m 本身叫频率改变。
- 修法：改为位置/相位组合超出训练覆盖，并连接后续频率缩放方法。

## 新增位置专题的一手依据（已复读方法，待实施）

2026-10-07 定向获取论文 HTML 后读取完整方法节点，避免 WebFetch 的全文截断：

- [ALiBi v2 §3](https://arxiv.org/html/2108.12409v2#S3)：固定、非学习的每头 slope；在已缩放 QK 分数上加 `−m_h(i−j)`（因果 `j≤i`）。原文脚注 10 明确 bias 不再乘 QK 的缩放因子。不要把仅距离偏置的单调性扩大为实际 attention 权重只由距离决定。
- [YaRN v3 §3.2](https://arxiv.org/html/2309.00071v3#S3.SS2)：令原窗口 `L`、扩展倍数 `s=L'/L`、波长 `lambda_d=2pi/theta_d`、旋转数 `r_d=L/lambda_d`；ramp 从 `r≤alpha` 的 0 过渡到 `r≥beta` 的 1。频率为 `(1−gamma(r_d))*theta_d/s + gamma(r_d)*theta_d`。高频保持，低频插值，中间混合；alpha=1、beta=32 是论文对 Llama 的经验设置，不是所有模型通用常数。
- [YaRN v3 §3.3](https://arxiv.org/html/2309.00071v3#S3.SS3)：YaRN 是上述分频策略加 attention 温度 `t`，分数除以 `t*sqrt(D)`。同时将 Q/K 乘 `a=sqrt(1/t)` 等价于分数乘 `a²`。论文经验式 `a=1+0.1ln(s)` 针对所测 LLaMA/Llama 2；不要把幅度因子 a 误写成分数因子 a。
- **原文内部冲突**：v3 §2.3 式 (9) 把 PI 写成 `g(m)=s*m`，但该文定义 `s=L'/L>1`；[附录 A.1 式 (16)](https://arxiv.org/html/2309.00071v3#A1.SS1) 明确使用 `mL/L'=m/s`，与压回原窗口的动机及 §3.2 的 `theta/s` 一致。教学采用 `m/s`，不能照抄式 (9) 的相反比例，也不需要把这处文献笔误塞进初学正文。
- 推荐手算：ALiBi 在 i=2、j=0,1,2、相同内容分数、slope=1/2 时加 `[-1,-1/2,0]`；YaRN 用 s=4、ramp 分别为 0、1/2、1，得到原频率的 1/4、5/8、1 倍（中间值写成 gamma=1/2，避免把 r 与 gamma 混淆）。新正文数字实施时独立重算。
