## 确认问题与建议

### F02-1（数学条件，需修复）：任意正交方向不满足 PCA 最优误差公式

- 位置：`content/chapter-02.js`，`math-pca`，“取 k 个正交方向”后的重建等式。
- 基线先只要求 `V_k` 的列正交，却把一般恒等式 `||Xc−XcVkVkᵀ||²=||Xc||²−tr(VkᵀXcᵀXcVk)` 直接接成 `N∑_{j>k}λ_j`。最后一步还要求 `V_k` 取协方差最大 k 个特征值对应的方向，且特征值按降序排列。
- 独立反例：本章四点、`C=diag(2,0.5)`、`N=4`，保留第一轴误差为 2；保留同样正交归一的第二轴误差为 8，不能都写成丢弃尾部特征值的 2。
- 修法：先给任意正交投影的恒等式，再声明最大特征子空间的最优值。补明 `V_kᵀV_k=I` 与降序；保留现有算例和白板答案。
- 验证：独立 Python 计算确认两个误差分别为 2、8，后续数值检查应验证这个适用条件。

### F02-2（代码操作说明，需修复）：gradient check 的检查点不明确

- 位置：`content/chapter-02.js`，`code` 结尾。
- 基线代码已执行 `w -= 0.001*d_loss_d_w`，紧接着建议比较 `L(w±epsilon)` 的差分与 384。若读者复用更新后的 `w=2.616`，实际差分约 154.319389。
- 独立计算：`w=3` 的中心差分为 384.000000012；`w=2.616` 为 154.319388682，步长 `1e-5`。更新后损失 27.186640191488 本身正确。
- 修法：明确用更新前 `w=3` 检查，或在代码中保存 `w_before_update` 并展示检查。无需修改正确的解析梯度和白板数字。

### G01（跨页面定义，需修复）：张量定义应包括零维

- 位置：`app/glossary.js` 的 `tensor`；`content/chapter-01.js` 的 `summary`。
- 01 正文正确地把标量、向量、矩阵都纳入张量；释义却写“一个或多个轴”，概述写“多个轴”。框架中的标量张量 shape 为 `()`，轴数为零。
- 修法：定义为零个或多个轴的数组；概述使用“带有轴和形状的数值表示”等不排除标量的表述。

### G02（跨领域同名，需修复）：统计 bootstrap 的释义被解释成价值自举

- 位置：`content/chapter-03.js` 的 `math-confidence`，以及 `app/glossary.js` 的 `bootstrap`。
- “bootstrap 应按用户或任务块重采样”指统计自助法；现有不区分大小写的全局释义只给“用当前价值估计构造尚未观测的未来目标”，会把正确正文配成错误提示。
- 修法：在同一释义中明确统计学为有放回重采样、RL 为用已有价值估计构造更新目标；不能把二者当成同一个算法。

### F03-1（复习条件，需收紧）：KL 模式覆盖与择模的限定没有带入面试答案

- 位置：`content/chapter-03.js`，`interview` 的 forward/reverse KL 追问。
- 正文已说明“在受限近似分布族里”“不是任意分布族的定理”，面试短答只剩“更偏向选择高密度模式”。无约束最优解两种方向都是 `q=p`；术语不应替代优化变量和分布族。
- 修法：在面试答案增加一句限定，说明这是受限近似时常见的趋势，两者充分表达时都可恢复 `p`。不重写正确的 KL 推导。

### F04-1（指标单调性，需修复）：Precision 与 Recall 不保证此消彼长

- 位置：`content/chapter-04.js`，`code` 开头。
- “改变 threshold，观察 Precision 与 Recall 如何此消彼长”暗示必然反向变化。固定分数降低阈值时 recall 不降，但 precision 可以上升或下降。
- 本章原数据已给反例：阈值从 0.8 降到 0.7，计数由 TP=1/FP=1/FN=2 变为 TP=2/FP=1/FN=1；precision 从 1/2 升至 2/3，recall 从 1/3 升至 2/3。
- 修法：让读者观察两者变化，并明确 recall 的单调性与 precision 的非单调性；不改变正确代码。

### F04-2（术语，需修复）：NB 的未出现不能写成缺失值

- 位置：`content/chapter-04.js`，`whiteboard` 的 Bernoulli NB 答案末句。
- “对缺失的二值特征还需乘 1−phi”会把观测到 `x_j=0` 与未知/缺失的特征混淆。正文正确讨论的是词未出现、即观测零值；真正缺失通常应按模型边缘化或另设缺失机制。
- 修法：明确“对观测到取值为 0 的二值特征”。可同步把 macro-F1 的一句说明写成“先计算每类 F1，再平均”，消除先平均 P/R 的歧义。
