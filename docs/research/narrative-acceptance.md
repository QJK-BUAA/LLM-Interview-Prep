## 实际修订

上一版将学习目标、公式索引和知识路线放在具体问题之前，第 00 章又把尚未学习的风险、似然与策略梯度列为入门要求。推导虽然有定义和手算，仍常从符号直接起步。对应修订如下：

| 断层 | 当前行为及可检查位置 |
| --- | --- |
| 第 00 章先给高阶考纲 | `00/intuition` 用三位同学的时长与分数说明模型、参数、误差和训练；`00/example` 比较两组参数，解释 18.67 是平方误差而非少考的分数 |
| 告诉新手跳读，实际仍先遇见展开公式 | 00 的实际正文先排主线图、参数更新代码、岗位路线，再排回访推导；02 后看更新，03 后看似然与分布错配，15 后看奖励梯度 |
| 每章开头像名词目录 | 30 章均以具体任务开场，真实前三节为 `intuition → example → roadmap`；例如 04 用欺诈漏报、19 用学生错误前缀、25 用找箱子的工具轨迹 |
| 公式缺少计算目的和结果解释 | 全部推导先给文字任务，再交代变量与假设，解释推导步骤与读数；不同教学例切换时说明为什么换数字，不将其当作厂商实测 |
| 同一公式的局部系数被读成最终效果 | 17 区分组优势、长度权重和参数梯度；19 区分固定前缀 KL 与轨迹分布梯度；24 把更新目标、配对证据与预算分别核算 |
| 面试模式失去上下文 | 面试模式保留开场，公式索引默认展开；学习模式将索引默认收起。两模式的推导正文仍默认展开 |
| 来源映射只能证明命中关键词 | 新增逐篇阅读说明，列出 37 份原文的具体小节、实际机制、课程落点和采用/修正/未采用理由；00 的四条来源锚点随训练全景移至 `diagram` |

页面正文顺序为：章节标题与摘要 → 开场问题 → 学习目标 → 手算例子 → 学习路线 → 公式索引 → 后续正文。目录、搜索、链接和完成按钮继续使用原 sections，不维护另一份隐藏正文。

## 主代理的教学复核

主代理查看了 30 个开场和全部 139 个推导的引入与收束；对于末尾保留追问链的章节，连同前面的数值解释一起检查。另逐段精读以下完整教学链：

- **00**：预测 48/56/64 → 低估 2/4/6 → 平均平方误差 → 留出评估；先完成初读任务，后续回访再核算斜率 8 到约 8.93、损失 18.67 到 5.31。
- **02**：计算链的参数变化 → 矩阵梯度 → 二次目标步长 → 特征方向与 SVD → PCA → 岭回归和 Lasso；区分重建目标与标签拟合目标。
- **04**：全报正常的高准确率 → 欺诈成本 900 对 300 → 概率与成本阈值 → 各类模型 → 排序与偏差方差；各方法都回到独立评估。
- **09**：当前位置读历史 → 批量注意力与因果 mask → Q/K/V 反向 → 计算成本 → 残差路径。反向手算换为 `[0, log 3]` 分数前已解释其目的是得到 1/4、3/4 的可算权重。
- **16**：人的偏好顺序 → RM 训练 → 冻结评分与 reference 代价 → 优势 → old/current 裁剪；正负优势的四种分支保留 ratio 导数。
- **17**：同题四份解答 → 中心化、标准化与 RLOO → 完整 token 目标 → DAPO 数据筛选、长度分母和超长反馈；不把这三种变化统称为精确信用。
- **19**：学生错误前缀 → 教师分布 → 两向 KL logit 梯度 → 早期动作改变后续前缀 → 特权信息可迁移边界。纠正开场的“无论怎样续写都答不对”，并把 softmax Jacobian 回补指向第 05 章。
- **25**：查目录、读文件、提交位置 → 可见历史与隐藏状态 → 只计算模型动作概率 → 按轮次/真实时间折扣 → worker 截断与任务终止。合成仓库任务不会被误称为 GitHub 原仓库。

各组逐推导记录可查 [00–04](narrative-audit-00-04.md)、[05–12](narrative-audit-05-12.md)、[13–19](narrative-audit-13-19.md)、[20–24](narrative-audit-20-24.md)、[25–29](narrative-audit-25-29.md)。这些具体解释是教学复核依据，下面的数量仅用于防止遗漏。
