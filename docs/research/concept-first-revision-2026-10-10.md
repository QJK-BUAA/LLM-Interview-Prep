# 概念优先修订记录

日期：2026-10-10

## 反馈

课程可见正文包含过多数字计算。即使详细推导默认折叠，许多“最小例子”和基础自测仍要求读者连续代入公式、计算小数、换算预算或记忆报告数字。这使首轮阅读变成算题，而不是建立概念和面试判断框架。

## 修订原则

- 可见例子负责解释对象、机制、方向和边界。
- 基础自测只检查定义、区别、更新方向、适用条件和排错判断。
- 精确计算、矩阵推导、概率估计与资源换算保留在折叠推导和白板练习中。
- 代码继续可运行，但正文不要求读者手算输出。
- 工业报告的实证数字仍保留在对应资料或推导中，不作为首轮记忆任务。

## 实际修改

重写全部 31 章的 `example` 小节，并定向改写所有基础 `quiz` 中的计算题。典型变化：

| 原可见内容 | 修订后 |
|---|---|
| 梯度例逐项得到具体大数和更新后小数 | 沿计算链解释串联相乘、分叉相加及学习率边界 |
| 注意力例计算点积、softmax 和输出向量 | 用指代读取解释 Query、Key、Value 与 mask |
| 显存例连续换算 GB、MiB 和并发容量 | 区分训练状态、激活与 KV Cache 三类账单 |
| PPO/GRPO/DPO/OPD 例计算 ratio、优势和 KL | 比较监督来源、更新方向与方法边界 |
| 工业案例计算报告成本与查询方差 | 说明怎样读阶段、预算、评测设置和归因 |
| Agent 例计算回报、ESS、软基线和概率比 | 区分动作、观测、过程信号、分布失配与关键路径 |

阅读指引中的完成条件也同步移除具体数值，改为可复述的概念验收。

随后继续复查 `intuition`、`roadmap`、`diagram`、`pitfall`、`comparison` 和 `interview`，删除旧算例在其他可见位置的残留。工业报告的详细版本与成绩材料从可见对比表移入已有折叠推导。

按非代码、非白板的首轮可见文本统计：

| 指标 | 修订前 | 修订后 |
|---|---:|---:|
| 数学公式出现位置 | 530 | 193 |
| 算术步骤 | 419 | 27 |
| 数字字面量 | 2187 | 603 |

算术步骤减少约 94%，数字字面量减少约 72%。剩余数字主要是章节编号、方法版本、shape 和必要单位，不再要求连续手算。

## 自动约束

新增 `tests/concept-first-content.test.mjs`：

- 可见例子最多保留一个 display 公式；
- 禁止在可见例子中堆叠算术步骤与大量数字字面量；
- 基础自测不要求计算具体概率、损失、回报、比率、优势、梯度、显存或成本。
- 其他可见正文同样限制 display 计算和连续算术步骤，防止旧算例转移到路线或面试段落。

shape 和单位的语义识别仍允许保留，但复杂计算必须移入白板。
