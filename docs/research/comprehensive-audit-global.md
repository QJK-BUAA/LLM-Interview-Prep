## 新增内容的一手依据与可复算设计

### 06 调度

- 已完整读取 [SGDR v5 §3](https://arxiv.org/html/1608.03983v5#S3)：cosine 从最大到最小学习率，重启重新升高学习率但保留参数。Warm restart 不等于 warmup。
- 本课采用明确标为教学组合的线性 warmup＋不重启的单段 cosine，不冒充原版 SGDR 全配方。
- 建议记号：总优化步 T、warmup 步 W，0≤W<T；u 表示调度进度。0≤u<W 时 `η=ηmax*u/W`；W≤u≤T 时 `ηmin+(ηmax−ηmin)*(1+cos(π(u−W)/(T−W)))/2`。W=0 跳过首分支；T 后保持 ηmin。说明实际第一个 optimizer update 用哪个 u，消除框架 off-by-one；例如本文从 u=1 使用。
- 手算 W=2、T=10、ηmax=.001、ηmin=.0001：u=1/2/6/10 为 .0005/.001/.00055/.0001。累积 4 个 microbatch 才做一次 optimizer update 时，应每四批推进一次调度；改变 batch/token 预算要重新解释 T。

### 08 截断采样

- 已完整读取 [Nucleus Sampling v2 §3.1–3.3](https://arxiv.org/html/1904.09751v2#S3.SS1)：按最高概率构造最小累计集合，保留总质量后重归一化；top-k 固定候选数，top-p 按分布形状改变。
- 用 `p=[.4,.3,.2,.1]`：k=2 后 `[4/7,3/7,0,0]`；阈值 .8 要保留前三项，成为 `[4/9,1/3,2/9,0]`。只保留“累计≤.8”的前两项是错误的。
- 先 top-k=2 再在其归一化结果用 top-p=.8，与直接在原分布 top-p=.8 的支持不同。明确本文指定顺序，接口依库核对，不声称各库完全相同。
- 原分布给第四项 .1，截断行为分布给 0；无法靠单 token IS 还原该项。与 16、28 的实际行为分母一致。

### 11 投机解码

- 已完整读取 [Fast Inference from Transformers via Speculative Decoding v2 §2、§3.1–3.3、A.1](https://arxiv.org/html/2211.17192v2#S2)。
- p 为目标、q 为草稿（均已包含指定温度和截断）；draft token `x~q` 的接受率 `min(1,p(x)/q(x))`，总接受率 `a=∑min(p,q)=1−TV(p,q)`。
- 拒绝时从 `[p−q]_+ / (1−a)` 采修正 token；证明 `min(p,q)+(1−a)*residual=p`。p=q 时没有拒绝，不计算 0/0；q 无需覆盖 p 全支持，因为 residual 可补上 q=0 的目标 token。这与只靠 IS 估计的支持要求不同，需明确。
- 手算 p=(.5,.3,.2)、q=(.2,.5,.3)：接受概率为 (1,.6,2/3)，接受质量(.2,.3,.2)，a=.7，残差分布(1,0,0)，混合恢复 p。拒绝后直接从 p 重采会得到(.35,.39,.26)，不是 p。
- K 个草稿逐个沿已接受前缀验收，首次拒绝后丢弃其余草稿/KV，采 residual；全接受再从目标下一分布采一 token。相同 vocab/token 事件与一致前缀是这份基本算法前提，跨 tokenizer 需另法。
- 独立同率近似下 `E[M]=1+a+...+a^K`，a=1 用 K+1；K=3、a=.7 得 2.533。一轮成本 `K*t_d+t_verify`，相对普通一 token 成本 t_target 的理想加速为 `E[M]*t_target/(K*t_d+t_verify)`。若 t_d=.1*t_target、t_verify=t_target，则约 1.94846；不能保证任何硬件/负载下都加速。提前 EOS、变动接受率和并行验证成本另处理。
- MTP 是获得多位置预测/草稿的一种机制，不等于接受校正算法；无需为了本节扩写所有树草稿变体。

## Glossary 统一（G01/G02 与其余定义）

以下全局释义会直接覆盖正文，应一并修订而非只修某章：

- tensor：零个或多个轴；01 summary 同步不排除标量。
- loss：可优化的标量目标，不要求处处可微；梯度法常用可微或次可微代理。
- rank：张量语境有时指轴数，矩阵 rank 才是线性独立方向；LoRA 为瓶颈维数。
- policy：可为确定性动作规则或条件概率分布，可依历史/观测。
- baseline：旨在降低方差，合适且满足条件才有效；不能保证任意基线降方差。
- on-policy：目标/行为策略一致；PPO 算法家族惯例与固定 old 多轮更新的近似分开。
- bootstrap：统计为有放回重采样，RL 为用当前价值估计构造更新目标。
- Monte Carlo：通用随机采样估计期望；RL 中 MC return 是其应用。
- rollout：策略产生的采样序列，可以完整 episode 或有限片段。

不为这些纯措辞写字符串镜像测试。确保 tooltip 可读且在桌面/触摸/键盘入口可访问。
